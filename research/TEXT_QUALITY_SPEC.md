## Acceptance criteria defined before implementation

- Scan every in-scope question stem and option; retain out-of-scope records unchanged. Also scan linked passages as separately identified context. Stable IDs, source pages, original fields, aliases and accepted decisions survive.
- Produce a separate proposed text view and per-field change log. Normalize Unicode composition and nonsemantic whitespace only. Keep legally meaningful symbols, numbers, negatives, punctuation and case names. Flag unusual glyphs, replacement/control characters, mixed digit/letter words and tokens absent from a pinned English frequency lexicon. Absence is not proof of error; retain names, Latin and source typos until source checked. Log token offsets and field paths; never silently spell-correct.
- Luna reads local source images for flagged candidates, preserving case/citation/date evidence and uncertainty. Record requested model, prompts, date, images/hashes and raw outputs. No dictionary or model response establishes legal correctness. Apply source-supported changes only in a separate AI proposal layer; human review status remains unreviewed.
- Synthetic tests must first fail for traceable whitespace cleanup, symbol/negation preservation, lexicon flags including apostrophes, malformed tokens, in-scope coverage, input immutability, and refusal to overwrite. Benchmark tests first fail for correct character/word edit distances, missing/extra items/options and critical-token errors; missing human references must block an accuracy pass.

## Benchmark frozen before reference annotation

Keep a synthetic software challenge suite, targeted known-defect challenge set and independently sampled source-page benchmark separate. Use all eleven selected year labels, with native/OCR strata where present. Select up to five pages per year/method without replacement with seed 20261111, from configured body pages including pages with no proposals. Record population sizes and sampling fractions; do not treat this disproportionate sample as an unweighted corpus accuracy estimate. Include all visible question starts and continuations on sampled pages, with adjacent-page context, and preserve page inclusion denominators. Targeted defect pages remain a separate challenge set even if they overlap by chance. Freeze baseline and proposed text before human reference comparisons; do not use the held-out human sample to tune cleanup rules.

Two independent humans transcribe source pages blind to extraction/proposals. Preserve both readings, uncertainty and adjudication; gold status requires both reviewer identities, completed independent readings and adjudication. Source typos remain literal. Legal review is separate. AI readings are development proposals and never gold.

Compare raw extraction and cleaned proposals against the same adjudicated reference, using NFC plus whitespace folding only (case, punctuation, negation, numbers and spelling preserved). Report micro CER = character edits / reference characters; micro WER = word edits / reference words; exact field/item accuracy; complete/ordered/labeled options; question start precision/recall and split/merge counts; passage-link/boundary accuracy where adjudicated; critical-token errors for negation, dates, section/article numbers, citations and case names. All rates show numerator/denominator, missing references, excluded/unreadable text and stratum results. CER/WER can exceed 100 percent with insertions. Never align missing items away. Gold alignment is explicit and human checked; machine IDs alone cannot identify missed questions.

Proposed release gates (targets, not achieved findings): CER <= 0.5 percent; WER <= 1 percent; question precision and recall >= 99 percent; fully correct options >= 99 percent; zero observed critical-token errors; no unresolved missing/split/merged items in the evaluated set. Report uncertainty and stratum minima; aggregate success cannot hide a failing stratum. Passing a small sample does not prove these rates corpus-wide. With zero errors, at least 299 independent observations are needed for a one-sided 95 percent binomial lower bound above 99 percent; page clustering and stratification require a suitable design-based/cluster analysis rather than treating all characters as independent. Human gold is not yet available, so current empirical accuracy is NOT ESTABLISHED and the gate remains NOT ASSESSED.
